# Automation, Findings And Control Drift

This module develops the reasoning needed to compare configuration scanning, policy enforcement and runtime detection.

## Learning Goals

- Compare configuration scanning, policy enforcement and runtime detection.
- Interpret findings through scope, version and effective behavior.
- Explain control drift and reproducible corrective changes.
- Relate exception review and evidence retention to continuous assurance.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
