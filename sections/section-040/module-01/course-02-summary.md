# Summary

Security automation scans declarations, enforces selected decisions or detects supported runtime behavior. These functions have different coverage and limits, so results need target, rule and version context.

Continuous assurance observes drift, evaluates findings, records durable corrections and verifies actual behavior. Exceptions and retained evidence require ownership and protection. Tool count alone does not establish control effectiveness.
