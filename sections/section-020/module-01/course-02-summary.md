# Summary

Threat modelling describes assets, actors, flows and trust assumptions, then asks how those relationships can cause harm. STRIDE provides a set of threat categories that helps structure the questions.

Prioritization and mitigation require the actual consequence and operating context. Record residual risk, ownership and evidence, and revise the model when dependencies or authority change. A completed template is not proof that every threat is addressed.
