# Structured Threat Modelling

This module develops the reasoning needed to explain a repeatable asset, data-flow and threat analysis process.

## Learning Goals

- Explain a repeatable asset, data-flow and threat analysis process.
- Use STRIDE categories without treating them as an automatic risk score.
- Relate proposed mitigations to specific trust-boundary failures.
- Describe residual risk and model updates after a design change.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
