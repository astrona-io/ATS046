# Threat Modelling Frameworks

This section teaches structured threat modelling. These ideas help you explain system behavior and choose a suitable approach in a KCSA scenario.

You will work through Structured Threat Modelling. Each module introduces its goals, teaches the concepts through examples, and closes with a summary. Reusable YAML checkpoints review related objectives after selected section summaries. The course assessment index records their placement and coverage.

## Learning Outcomes

- Explain a repeatable asset, data-flow and threat analysis process.
- Use STRIDE categories without treating them as an automatic risk score.
- Relate proposed mitigations to specific trust-boundary failures.
- Describe residual risk and model updates after a design change.
