# Supply Chain Assurance Evidence

This module develops the reasoning needed to relate source, build and artifact records to an assurance requirement.

## Learning Goals

- Relate source, build and artifact records to an assurance requirement.
- Distinguish SBOM, provenance, signature and verification decision.
- Explain the limits of framework levels and attestations.
- Describe retention and exception handling for release evidence.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
