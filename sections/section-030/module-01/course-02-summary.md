# Summary

Supply chain assurance links source, build, artifact and deployment evidence. Inventories, provenance, signatures and vulnerability findings demonstrate different properties and need trustworthy producers.

Framework levels and development practices have defined scope rather than guaranteeing defect-free software. Preserve exact identity, acceptance outcomes, exceptions and later findings so a release's assurance remains reviewable over time.
