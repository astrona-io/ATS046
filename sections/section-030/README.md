# Supply Chain Compliance

This section teaches supply chain assurance evidence. These ideas help you explain system behavior and choose a suitable approach in a KCSA scenario.

You will work through Supply Chain Assurance Evidence. Each module introduces its goals, teaches the concepts through examples, and closes with a summary. Reusable YAML checkpoints review related objectives after selected section summaries. The course assessment index records their placement and coverage.

## Learning Outcomes

- Relate source, build and artifact records to an assurance requirement.
- Distinguish SBOM, provenance, signature and verification decision.
- Explain the limits of framework levels and attestations.
- Describe retention and exception handling for release evidence.
